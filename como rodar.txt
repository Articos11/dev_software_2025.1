1 - Inicializar um ambiente virtual com o comando: 
python -m venv .venv 

2 - Obter a chave de acesso da API. 

3 - criar um arquivo .env na pasta server. 

4 - Mudar para a pasta do servidor: 
cd server

5 - Iniciar o ambiente virtual:

source .venv/Scripts/activate (Windows)
source .venv/bin/activate (Linux)

6 - Instalar as bibliotecas externas:

pip install -r requirements.txt

7 - Rodar o arquivo o servidor
py api.py (Git Basch)
python api.py (PowerShell)

8 - Utilizar o live server (Exntesão) para rodar o index.html.

## PARA RODAR A APLICAÇÃO REACT ##

1 - Mudar para o diretório da aplicação
cd resumeai-react

2 - Instalar dependências
npm install

3 - Inicializar o servidor de desenvolvimento
npm run dev
// OBS.: Ctrl + C serve para parar o servidor

Tudo pronto!
