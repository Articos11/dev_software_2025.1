## PARA RODAR O SERVIDOR ##

1 - Clonar o repositório do sprint 3 
    a - Inicie o repositório git localmente (git init)
    b - Adicione o repositório remotamente (git remote add origin https://github.com/Articos11/dev_software_2025.1)
    c - troque para a branch sprint3 (git checkout sprint3) 
    d - Pegue os dados do repositório (git pull)

2 - Acessar a pasta do servidor utilizando cd server no terminal

3 - Criar um ambiente virtual de python
    python -m venv .venv

4 - Inicializar o ambiente virtual 
    source .venv/Scripts/activate (Windows)
    source .venv/bin/activate (Linux)

5 - Instalar as dependências de Python no ambiente virtual
    pip install -r requirements.txt

6 - criar um arquivo chamado .env na pasta do servidor
    Inserir a chave da api. Solicitar via zap pra testes!!

6 - Rodar o servidor 
    python3 server.py (PowerShell)
    py server.py (git Bash)

7 - Ativar o html da pasta client com o liveserver (essa parte vai ser mudada porque estamos recriando o front com react.)



## PARA RODAR A APLICAÇÃO REACT ##

1 - Mudar para o diretório da aplicação
cd resumeai-react

2 - Instalar dependências
npm install

3 - Inicializar o servidor de desenvolvimento
npm run dev
